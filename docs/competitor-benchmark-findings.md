# Competitor benchmark findings

## Screener.in — verified public capabilities

The official Screener.in features page confirms long-horizon company analysis on 10+ years of financial data, export to Excel, segment results, watchlists, insider-trade updates, credit-rating tracking, announcements, automated pros/cons, peer comparison, volume charts with delivery, automatic screen alerts, consolidated/standalone handling, custom columns, and custom ratios. The official guides also describe saved screens, screen alerts, watchlists, announcement and insider-trade feeds, and Excel customization. The annual-reports page exposes recent annual reports with sales/profit summary and links to BSE/NSE-hosted documents.

## Skillnet.in — verification result

The direct domain `https://skillnet.in` resolved to `/lander` with no readable public product content or detected interactive elements in the available page. Public search results did not establish that this domain is an Indian equity-research platform; several results referred to unrelated SkillNet enterprise or talent-management products. Therefore, no Skillnet-specific stock capability is being claimed or copied. The benchmark will use only capabilities that can be verified on the requested domain or authoritative public sources.

## Gap candidates for implementation

The highest-value verified gaps relative to the current app are: saved custom screens with reusable conditions, peer comparison with historical metrics, watchlist/news/insider/credit-rating activity aggregation, annual-report and filing links, custom columns/ratio definitions, delivery-aware volume context, and exportable research snapshots. These must be implemented with explicit source and freshness labels; unavailable licensed data must not be replaced with invented values.

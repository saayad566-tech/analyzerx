This matrix reflects the current implemented registry and is intentionally truthful. `Imported` means the platform has an adapter or source-record path for the dataset; it does not mean every provider is currently fresh or configured. Protected, paid, unresolved, or periodic boundaries remain visible in the limitation column.

## Current vertical-slice result

The typed registry is available through `capabilities.list` and `capabilities.matrix`. The Admin operations screen displays the matrix next to collector/provider telemetry. The Company Detail route now calls a source-backed `market.profile` aggregation that composes market snapshot, fundamental analysis, current news, symbol-scoped source records, official filing entry links, and derivatives data with isolated error states. The existing source-record and provider boundaries are preserved.

## Explicit remaining gaps

The matrix deliberately does not claim complete symbol-resolved filing coverage for every NSE/BSE category, live stock-level FII/DII sector flows, real-time mutual-fund transactions, live options without a verified provider, full entity-master alias history, or durable normalized market/fundamental observation tables. Those are follow-up vertical slices requiring validated source schemas or provider access; they must not be filled with mock values.

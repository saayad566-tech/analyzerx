# AnalyzerX environment reference

This document lists the runtime configuration keys used by AnalyzerX. Values must be entered through the project’s secure Secrets configuration; do not commit `.env` files or place credentials in client code.

| Group | Keys |
|---|---|
| Runtime | `NODE_ENV`, `PORT`, `ALLOWED_ORIGINS`, `DATABASE_URL`, `JWT_SECRET` |
| Browser and OAuth | `EXPO_PUBLIC_API_BASE_URL`, `EXPO_PUBLIC_APP_ID`, `EXPO_PUBLIC_OAUTH_PORTAL_URL`, `EXPO_PUBLIC_OAUTH_SERVER_URL`, `EXPO_PUBLIC_OWNER_NAME`, `EXPO_PUBLIC_OWNER_OPEN_ID`, `OAUTH_SERVER_URL`, `OWNER_OPEN_ID`, `EXPO_WEB_PREVIEW_URL`, `EXPO_PACKAGER_PROXY_URL`, `VITE_APP_ID` |

## Secure configuration rules

Secrets are server-only unless a key is explicitly prefixed with `EXPO_PUBLIC_` or `VITE_` and contains no credential. Production must define a strong random `JWT_SECRET`, a non-empty `ALLOWED_ORIGINS` list containing only trusted domains, and callback tokens for scheduled routes. Angel One and Dhan credentials are optional; missing values must remain visible as `auth_required` rather than being replaced with demo values.
